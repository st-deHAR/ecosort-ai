# 🌍 EcoSort AI | Arbiter Hacks V1

> **Eco-friendly waste sorting assistant powered by in-browser AI.**

EcoSort AI is an intelligent web application designed to help users identify and sort household waste accurately, sustainably, and privately—all directly within the browser without sending personal images to external servers.

---

### ✨ Key Features

- **🛡️ 100% Privacy-First (In-Browser AI):** Powered by `Transformers.js` and zero-shot CLIP classification running locally via WebAssembly (`WASM`). No images leave your device.
- **⚡ Instant AI Waste Scanner:** Upload an image or use quick demo samples to instantly classify items into categories (Plastic, Organic, Paper, Metal, etc.).
- **📊 Local Impact Tracking & Benchmarking:** Includes tracking features and model evaluation support to ensure high classification accuracy.
- **📷 No Camera Required:** Fully functional via manual image uploads and pre-loaded test samples for seamless demo testing.
